# 本地项目管理工具

一个轻量的本地项目管理工具，使用 Python 标准库和原生 JavaScript。项目和甘特图以 JSON 保存在本地，不依赖第三方包。

## 启动

### 手动启动

```bash
# 在项目目录下运行（Python 3.9+）
python3 app.py
```

### 开机自动启动（macOS）

已经配置好了 `launchd` 用户级服务，登录后会自动在后台运行：

```bash
# 查看状态
launchctl list | grep com.localpm

# 手动停止
launchctl unload /Users/jingyu/Library/LaunchAgents/com.localpm.app.plist

# 手动启动
launchctl load -w /Users/jingyu/Library/LaunchAgents/com.localpm.app.plist
```

然后打开浏览器访问：http://127.0.0.1:8765

## 功能

- 新建 / 编辑 / 删除项目
- 为每个项目添加任务，设置优先级
- 点击任务文字可直接修改标题
- 勾选复选框标记完成
- 搜索项目或任务
- 导出 / 导入 JSON 数据
- 甘特图日 / 周 / 月视图、拖动排期、进度、里程碑和撤销
- 项目任务与甘特图任务的可选关联
- 保存冲突检测、完整备份和导入前自动备份

## 保存与冲突

甘特图修改会依次自动保存。两个页面同时编辑、恢复备份或直接修改数据文件时，旧版本保存会被拒绝，避免静默覆盖。

遇到冲突时，本页修改仍然保留：先点击“下载本页草稿”，再“加载最新版本”，对照草稿重新应用需要的修改。草稿用于保留和比对本页规划，不是完整备份，不能直接用于“导入 / 恢复”。网络或磁盘错误可点击“重试保存”。有未保存修改时，离开页面会收到浏览器提示。

## 关联项目任务

在甘特图任务编辑框中选择“关联项目任务”。一个项目任务最多关联一个甘特图任务：

- 甘特图进度为 100% 时，关联项目任务标记完成；低于 100% 时标记未完成。
- 在项目列表勾选完成，会把关联进度设为 100%；取消完成将 100% 重置为 0%，已有的部分进度保持不变。
- 删除项目或项目任务时，甘特图条目保留，仅解除关联。删除甘特图条目不会删除项目任务。
- 任务名称和排期独立维护。其他已打开页面刷新后显示最新状态；有过期修改的甘特图页面会提示保存冲突。

## 备份与恢复

主页“完整备份 JSON”和甘特图“备份 JSON”会导出同一份完整备份，包含 `schemaVersion: 1`、`projects` 和 `roadmap`。“打印 / PDF”用于分享图表，不能用于恢复数据。

通过主页“导入 / 恢复”选择 JSON 文件。导入前完整校验数据；校验通过后，旧数据自动备份到 `data/backups/before-import-*.json`，然后替换数据。该备份可通过同一入口恢复。磁盘无法保存备份时不会开始覆盖。

兼容旧版仅含 `projects` 的 JSON：只替换项目，保留甘特图内容并更新关联状态。`{"projects": []}` 会清空项目；需要清空两者时，应导入包含空项目和空 `roadmap.lanes` 的完整备份。

## 数据文件

数据保存在项目目录下：

```
data/projects.json
data/roadmap.json
data/backups/
```

可直接查看或备份 JSON 文件。手工编辑建议先停止服务，避免与正在保存的操作互相覆盖；日期使用有效的 `YYYY-MM-DD`，甘特图起止日期均包含当天。

关联同步和恢复备份需要同时修改两个数据文件，服务使用临时事务文件 `data/.pending.json`；如果进程中断，下次读取时会完成恢复。发现此文件时不要手动删除。

## 验证

Python 测试使用临时目录和随机本地端口，不修改实际数据。前端逻辑测试需要 Node.js（仅测试需要，运行应用无需 Node.js）。

```bash
python3 -m unittest discover -s tests -v
node --test tests/frontend.test.js
```

代码分工：`app.py` 处理 HTTP，`models.py` 负责数据校验和任务同步，`storage.py` 负责持久化、版本和备份，`static/save-queue.js` 负责前端保存队列。
